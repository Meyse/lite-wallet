# Tauri + SvelteKit + TypeScript

This desktop wallet uses Tauri, SvelteKit, TypeScript, and Vite.

Use Node `22.23.2` and the package-manager version pinned in `package.json`:

```sh
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```
